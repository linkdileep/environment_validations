# Environment Validations

Automation ecosystem validation repository created during Phase 0A.

## Purpose

This repository verifies that the automation environment is correctly configured before framework development begins.

The goal is to validate:

* Language runtimes
* Dependency managers
* Repository workflows
* Testing frameworks
* Browser automation capabilities

---

## Java Ecosystem

### java_smoke_test

* JDK installation
* Compilation
* Execution

### java_maven_smoke_test

* Maven
* Dependency resolution

### java_playwright_smoke_test

* Playwright integration
